# Public README Assets

`public-demo-page-1.png` is a rendered first page of the repository's public
example. It was generated from `examples/demo-report.md` with
`profiles/public-demo.toml`, then passed through the optional Microsoft Word
field-update and PDF-export pass before rasterization.

The image contains only newly authored demonstration text, a generic template,
and system-rendered typography. It contains no customer, course, competition,
or project-delivery asset.
